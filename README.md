# 💻 Aulas de Programação Web — UNINASSAU

> Repositório criado para acompanhar a disciplina de **Programação Web** do curso de Ciência da Computação na UNINASSAU.  
> Aqui registro minha evolução com HTML, CSS e JavaScript — do básico ao avançado — aula por aula.

---

## 📋 Sobre o Repositório

Este repositório tem dois objetivos principais:

- 📚 **Organizar o conteúdo** das aulas (exercícios, slides e materiais do professor)
- 🛠️ **Praticar Git e GitHub** no dia a dia, versionando cada aula como um commit real

Cada pasta representa uma aula. Os arquivos `.pdf` são os materiais disponibilizados pelo professor.
